# JAVA프로그래밍응용 2주차 배운 내용 정리

## 1. 객체와 클래스
- **객체(Object)** : 속성과 동작을 가지는 식별 가능한 대상
- **클래스(Class)** : 객체를 생성하기 위한 설계도
- **인스턴스(Instance)** : 클래스로부터 실제 생성된 객체
- `new` 연산자로 객체를 생성하고 참조변수로 접근

## 2. 클래스의 구성
- **필드(Field)** : 객체의 상태를 저장하는 변수
- **메서드(Method)** : 객체의 동작을 정의하는 함수
- **생성자(Constructor)** : 객체 생성 시 호출되어 초기화 수행
- 생성자는 클래스명과 이름이 같고 반환 타입이 없음
- 생성자를 직접 선언하면 매개변수가 없는 기본 생성자가 자동 제공되지 않음

## 3. 메서드의 특징
- **매개변수(Parameter)** : 메서드 실행 시 전달받는 값
- **반환 타입** : 메서드 실행 결과를 돌려주는 자료형
- **오버로딩(Overloading)** : 이름이 같고 매개변수 목록이 다른 메서드를 여러 개 선언하는 것
- 메서드를 호출하는 대상과 인수의 전달을 구분

## 4. 인스턴스 멤버와 정적 멤버
- **인스턴스 필드·메서드** : 개별 객체에 속하는 멤버
- **정적 멤버(static)** : 클래스에 속해 객체들이 공유하는 멤버
- 정적 멤버는 일반적으로 `클래스명.멤버명`으로 접근
- 모든 객체에 같은 데이터를 공유할지 개별 데이터를 둘지 판단

## 5. 메서드 인수 전달
- Java는 인수를 **값으로 전달(Call by Value)**함
- 기본 자료형은 값이 복사되어 전달됨
- 객체와 배열을 전달할 때는 참조값이 복사되어 전달되므로 같은 객체의 내용은 변경될 수 있음

## 6. 객체 배열
- 객체 배열에는 객체 자체가 아니라 **객체를 가리키는 참조값**이 저장됨
- 배열 생성과 개별 요소의 객체 생성은 구별
- 여러 객체를 순서대로 관리할 때 활용

## 7. 핵심 정리
- 클래스, 객체, 생성자, 필드, 메서드의 역할 구분
- 오버로딩과 static 멤버의 사용 목적 이해
- 기본형·참조형 인수 전달의 동작과 객체 배열 구조 확인
