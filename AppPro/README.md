
## 1. 프로젝트 개요

스마트폰과 주변기기의 **제품 정보, 가격, 사양 등을 한곳에서 확인하고 비교할 수 있는 앱**임.

사용자가 제품 구매나 교체에 필요한 정보를 쉽게 확인하고 합리적으로 선택할 수 있도록 지원함.

## 2. 문제 정의

| 구분 | 내용 |
| --- | --- |
| **사실** | 제품 정보가 여러 사이트에 분산되어 있어 제품별 사양과 가격을 직접 찾아 비교해야 함 |
| **가정** | 사용자는 제품의 성능뿐 아니라 호환성, 디자인, 실제 사용 환경 등도 중요하게 생각하며, 이를 직관적으로 확인하면 제품 선택에 도움이 될 것으로 예상함 |

## 3. 핵심 가치

- 정보 탐색의 **편의성**과 제품 비교의 **직관성**을 높임
- 여러 사이트를 방문할 필요 없이 제품 정보를 통합 제공하고, 사용자가 자신에게 적합한 제품을 보다 쉽게 선택할 수 있도록 함

## 4. 주요 기능

| 기능 | 설명 |
| --- | --- |
| **제조사 및 제품 탐색** | 삼성·애플의 스마트폰, 태블릿, 이어폰, 스마트워치, 노트북 탐색 |
| **제품 상세 정보** | 공식 사양, 출시일, 옵션별 가격 확인 |
| **3D 제품 뷰어** | 실제 제품의 외형을 360도 회전·확대하여 확인 |
| **제품 비교** | 동일 종류의 여러 제품을 나란히 비교 |
| **구매 정보** | 최저가, 구매 가능일 및 보상판매 예상 금액 확인 |
| **교체 비용 분석** | 기존 제품의 중고 판매, 수리 및 신규 구매 비용 비교 |

## 5. 기대 효과

- 여러 사이트에 분산된 제품 정보를 한곳에서 확인할 수 있음
- 제품별 사양과 디자인의 차이를 직관적으로 파악할 수 있음
- 보상판매 및 중고 시세를 반영해 실질적인 구매 부담을 비교할 수 있음
- 사용자의 상황과 예산에 적합한 제품 선택을 지원함

## 최종 목표

**제품 탐색·비교부터 구매 및 교체 비용 분석까지 지원하는 스마트 기기 통합 플랫폼 구축을 목표로 함.**

---

> **참고:** 위 기대 효과는 아직 검증되지 않은 예상 효과이며, 향후 사용자 테스트를 통해 확인할 계획임. 제품 정보는 제조사 공식 홈페이지를 기준으로 제공할 예정임.
