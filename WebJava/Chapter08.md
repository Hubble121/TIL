# 웹자바프로그래밍입문 8장 내용 정리

## 1. 쿠키(Cookie)
- **쿠키** : 브라우저가 관리하는 저장 공간에 이름과 값을 기록하는 데이터
- `new Cookie("userId", "lee")` : 쿠키 객체 생성
- `cookie.setMaxAge(60 * 60 * 2)` : 유지 시간 설정(초 단위)
- `response.addCookie(cookie)` : 응답에 쿠키 추가
- `request.getCookies()` : 요청에 포함된 쿠키를 배열로 가져옴
- **쿠키 조회** : `getName()`으로 원하는 이름을 찾고 `getValue()`로 값을 읽음
- **쿠키 삭제** : 같은 이름의 쿠키를 만들어 `setMaxAge(0)`으로 설정한 뒤 응답에 추가

## 2. 쿠키를 이용한 로그인 흐름
- 로그인 폼에서 `request.getParameter("id")`, `getParameter("pw")`로 값 수신
- 강의 실습은 고정된 계정을 확인하고 로그인 성공 시 `userId` 쿠키 생성
- 쿠키 존재 여부에 따라 **로그인 폼**과 **로그아웃 화면**을 구분
- `response.sendRedirect()`로 로그인 메인 화면으로 이동
- 쿠키 기반 인증은 학습용 예시이며 쿠키 자체를 신뢰하여 인증하는 방식과는 구별할 필요가 있음

## 3. 세션(Session)
- **세션** : 서버가 사용자별 상태를 관리하는 방식
- **세션 ID** : 사용자의 세션을 구별하는 식별자
- **session 속성** : 서버에서 로그인 ID, 사용자 이름 등의 값을 보관
- `session.setAttribute("userId", id)` : 값 저장
- `(String) session.getAttribute("userId")` : 값 조회 및 형변환
- `session.removeAttribute("userId")` : 특정 속성 삭제
- 일정 시간 요청이 없으면 세션이 만료될 수 있음

## 4. 쿠키와 세션의 차이
- **쿠키** : 브라우저에 데이터가 저장되고 요청 시 서버로 전달될 수 있음
- **세션** : 사용자별 상태를 서버에서 관리, 클라이언트는 세션 식별자를 보유할 수 있음
- 일반적인 로그인 상태 관리는 강의에서 **쿠키 실습 → 세션 속성 기반 실습** 순서로 학습
- 세션 데이터와 쿠키는 저장 위치와 역할이 다름

## 5. 세션 기반 로그인과 로그아웃
- **login_main.jsp** : 세션의 `userId` 존재 여부에 따라 로그인 상태 표시
- **login.jsp** : 제출된 ID·비밀번호를 확인하고 로그인에 성공하면 세션 속성 설정
- **logout.jsp** : 로그인 관련 세션 속성을 제거
- 로그인하지 않았을 때는 입력 폼을 표시하고, 로그인했다면 사용자 이름과 로그아웃 버튼 표시

## 6. 데이터베이스를 이용한 로그인
- **member 테이블** : `id`, `pw`, `name` 등 회원 정보 저장
- JDBC로 데이터베이스에 접속하여 입력된 계정과 일치하는 레코드 확인
- `ResultSet`에 해당 회원이 있으면 `userId`, `userName`을 세션에 저장
- 조회 결과가 없으면 로그인 실패 안내
- 실습의 단순 비밀번호 저장·조회 방식은 개념 확인용이며 운영 서비스의 안전한 인증 설계와는 다름

## 7. 회원가입과 정보 수정
- **member_join_form.jsp** : 회원가입 입력 폼
- **member_join.jsp** : 입력 확인 및 기존 ID 중복 확인 후 DB에 회원 추가
- **member_update_form.jsp** : 기존 회원 정보를 조회하여 수정 폼 구성
- **member_update.jsp** : 입력된 정보로 회원 레코드 수정
- 사용자 이름이 변경되면 세션의 `userName`도 새 값으로 갱신

## 8. 핵심 정리
- 쿠키의 생성·읽기·삭제와 세션 속성의 저장·조회·삭제 구분
- **폼 입력 → 계정 확인 → 세션 등록 → 상태별 화면 → 로그아웃** 흐름 이해
- DB 조회·회원가입·회원 정보 수정까지 연결되는 JSP 프로그램 구조 복습
