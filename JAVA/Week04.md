# JAVA프로그래밍응용 4주차 배운 내용 정리

## 1. 컬렉션과 제네릭
- **컬렉션(Collection)** : 가변 개수의 객체를 저장하고 관리하는 자료구조
- **제네릭(Generic)** : 저장하거나 전달할 자료형을 타입 매개변수로 일반화하는 방식
- `<E>`, `<K>`, `<V>` 등으로 자료형을 나타냄
- 컬렉션에는 객체 타입을 사용하며 기본 자료형은 `Integer`, `Double` 같은 래퍼 클래스로 다룸

## 2. Vector<E>
- **Vector** : 순서가 있는 가변 크기의 객체 목록
- `add()` : 요소 추가
- `get()` : 인덱스로 요소 조회
- `size()` : 저장된 요소 수 확인
- `remove()` : 요소 제거

## 3. ArrayList<E>
- **ArrayList** : 순서가 있으며 인덱스로 접근할 수 있는 리스트
- 자료 추가·조회·수정·삭제에 사용
- 배열과 달리 저장 요소 수에 따라 크기가 변할 수 있음
- `for`문 또는 반복 구문으로 여러 요소 순회

## 4. HashMap<K,V>
- **HashMap** : 키(Key)와 값(Value)의 쌍으로 데이터를 저장
- `K` : 키의 자료형 / `V` : 값의 자료형
- `put(key, value)` : 키와 값 저장
- `get(key)` : 키로 값 조회
- `remove(key)` : 특정 키의 요소 삭제
- 배열의 인덱스와 달리 **키를 통해 값에 접근**하는 것이 핵심

## 5. 반복과 컬렉션 선택
- 저장 순서와 인덱스가 필요하면 `ArrayList` 등 List 계열 검토
- 이름·ID 등 식별자와 값을 연결해야 하면 `HashMap` 활용
- 컬렉션의 반복 처리와 자료형 구분을 함께 이해

## 6. 핵심 정리
- 제네릭은 여러 클래스에 자료형을 지정해 타입 안전성을 높임
- `Vector<E>`, `ArrayList<E>`, `HashMap<K,V>`의 구조와 접근 방법 비교
- 특히 `HashMap<String, Integer>`와 `put()`·`get()`으로 값 저장·조회하는 흐름 복습
