# 웹자바프로그래밍입문 9장 내용 정리

## 1. 게시판 프로그램 구성
- **게시판** : 게시글의 목록·작성·조회·수정·삭제 기능을 제공하는 웹 애플리케이션
- JSP 화면과 처리 파일, 데이터베이스 테이블을 연결하는 실습
- 게시글 번호, 작성자, 제목, 내용, 작성 시각, 조회수 등의 필드를 관리

## 2. 게시글 목록
- **list.jsp** : DB에서 게시글 목록을 SELECT하여 화면에 출력
- `ResultSet`을 순회하여 여러 게시글을 표 형식으로 표시
- 게시글 번호를 전달하면 상세 화면으로 이동할 수 있음

## 3. 게시글 작성
- **write.jsp** : 작성자·제목·내용을 입력받는 폼
- **insert.jsp** : 폼의 값을 받아 DB에 INSERT 실행
- 필수 입력값이 비어 있는지 확인한 뒤 저장 처리

## 4. 게시글 상세 조회
- **view.jsp** : 전달받은 게시글 번호에 맞는 레코드를 조회
- 조회 결과의 제목·내용·작성자·시간 등을 표시
- 글 내용에 포함된 공백과 줄바꿈이 HTML에서 어떻게 표시되는지 확인

## 5. 게시글 수정
- 글쓰기 화면을 수정 화면과 공통으로 사용할 수 있음
- 새 글쓰기와 수정하기에 따라 폼의 초기값 및 전송 대상 구분
- **update.jsp** : 전달된 데이터를 기준으로 DB의 해당 게시글을 UPDATE

## 6. 게시글 삭제
- **delete.jsp** : 게시글 번호를 기준으로 해당 레코드를 DELETE
- 삭제 후 목록 화면으로 돌아가는 흐름 이해

## 7. 주요 데이터 흐름
1. 목록 요청 → DB 조회 → 여러 글 출력
2. 글쓰기 요청 → 입력 폼 → INSERT → 목록
3. 상세 조회 → 글 번호 전달 → SELECT → 내용 출력
4. 수정·삭제 → 글 번호 확인 → UPDATE/DELETE → 목록
