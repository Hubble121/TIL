# JAVA프로그래밍응용 3주차 배운 내용 정리

## 1. 접근 제한자와 캡슐화
- **public** : 외부에서 접근 가능
- **protected** : 같은 패키지 및 다른 패키지의 자식 클래스에서 접근 가능
- **default(패키지 접근)** : 같은 패키지에서 접근 가능
- **private** : 선언한 클래스 내부에서 접근 가능
- **Getter / Setter** : 외부에서 필요한 필드를 읽거나 변경할 때 사용하는 메서드

## 2. 클래스 상속
- **상속(Inheritance)** : 기존 클래스의 멤버를 새로운 클래스가 물려받는 방식
- `extends` 키워드를 사용
- **부모 클래스(Superclass)** / **자식 클래스(Subclass)** 관계
- 공통된 기능을 재사용하고 확장할 때 활용

## 3. 상속과 생성자
- 자식 객체 생성 시 부모 생성자의 실행이 선행됨
- `super()`로 부모 생성자를 호출
- 부모에게 매개변수 있는 생성자만 있다면 자식 생성자에서 적절한 `super(인수)` 호출 필요
- 부모 생성자 호출이 자동으로 되는 경우와 직접 지정해야 하는 경우 구분

## 4. 메서드 오버라이딩
- **Overriding** : 상속받은 메서드를 자식 클래스에서 재정의
- `@Override`를 통해 재정의 여부 확인
- `super.메서드()`로 부모의 메서드 구현을 호출 가능
- **Overloading** : 같은 이름의 메서드에 서로 다른 매개변수 목록 사용
- 오버로딩과 오버라이딩의 차이를 구분

## 5. 추상 클래스와 추상 메서드
- **abstract class** : 공통 기능을 정의하되 직접 인스턴스화하지 않는 클래스
- **abstract method** : 구현 본문 없이 선언한 메서드
- 자식 클래스에서 필요한 메서드를 구현하도록 구조를 정함
- 공통 동작의 통일과 상속을 통한 확장이 목적

## 6. 인터페이스
- **interface** : 클래스가 구현해야 할 기능의 계약
- **implements** : 클래스가 인터페이스를 구현할 때 사용
- 서로 다른 클래스도 동일한 인터페이스 타입으로 다룰 수 있음
- 추상 클래스는 공통 기반 구현 제공에, 인터페이스는 구현 계약 정의에 초점을 둠

## 7. 핵심 정리
- 상속 관계에서 부모·자식 생성자의 실행 순서를 이해
- 오버라이딩과 오버로딩은 적용 목적이 다름
- 추상 클래스와 인터페이스는 공통 기능과 구현 규칙을 정의하는 도구
