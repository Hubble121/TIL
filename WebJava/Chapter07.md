# 웹자바프로그래밍입문 7장 내용 정리

## 1. 파일 업로드
- 사용자가 웹 폼을 통해 파일을 서버에 전송하는 기능
- `<input type="file">`로 파일 선택
- `<form method="post" enctype="multipart/form-data">` 형식으로 전송
- **Multipart** : 파일과 일반 입력값을 함께 전달하는 방식

## 2. JSP에서 업로드 파일 처리
- 강의자료에서는 Tomcat 10 이후의 환경에 맞춰 **Part API**로 파일 업로드 처리
- `request.getPart("upload")` : 전달된 파일 항목 얻기
- `getSize()` : 전달된 파일의 크기 확인
- `getSubmittedFileName()` : 업로드된 파일의 이름 확인
- `write()` : 서버 지정 위치에 파일 저장

## 3. 파일 저장 위치와 중복 파일명
- 업로드 파일을 프로그램 코드와 구분된 폴더에 저장
- 같은 이름의 파일이 이미 존재하면 파일명 변경 등 충돌 처리
- 서버의 Multipart 처리 설정과 파일 크기 제한 확인

## 4. 간이 웹 하드 프로그램
- **웹 하드** : 업로드한 파일을 서버에 저장하고 목록·삭제 기능을 제공
- 파일의 실제 내용은 서버 폴더에 저장
- 파일명·크기·등록 정보 같은 메타데이터는 DB 테이블에 저장

## 5. 파일 추가와 삭제
- 파일 추가 : 업로드 요청 → 서버 파일 저장 → DB 기록 → 목록 화면 갱신
- 파일 삭제 : DB에서 대상 검색 → 저장된 파일 제거 → DB 기록 삭제
- 파일 시스템의 상태와 DB의 정보가 맞는지 확인하는 것이 중요

## 6. 핵심 정리
- HTML 업로드 폼과 `Part` 처리의 연결 구조 이해
- 파일 저장소와 DB 메타데이터의 역할 구분
- 같은 파일명 처리, 업로드·삭제의 순서를 파악
