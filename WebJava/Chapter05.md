# 웹자바프로그래밍입문 5장 내용 정리

## 1. MariaDB와 관계형 데이터베이스
- **MariaDB(MySQL 계열)** : 테이블 형태로 데이터를 관리하는 관계형 DBMS
- **DBMS** : 데이터베이스를 관리하고 쿼리 실행을 처리하는 소프트웨어
- **테이블(Table)** : 행과 열로 데이터를 저장하는 구조
- **레코드(Row)** : 테이블의 한 행
- **필드(Column)** : 테이블의 한 열

## 2. 서버와 클라이언트
- **MariaDB 서버** : 데이터베이스 저장과 요청 처리
- **HeidiSQL** : 데이터베이스에 접속하여 쿼리를 작성·실행하는 클라이언트
- 접속에 필요한 서버 주소, 포트, 계정, 비밀번호, 데이터베이스를 구분

## 3. 사용자와 권한
- **root** : 관리자 계정
- 일반 작업에는 용도에 맞는 일반 사용자 계정 사용
- 계정 생성과 데이터베이스 접근 권한 설정 개념 이해

## 4. 데이터베이스·테이블 명령
- `CREATE DATABASE` : 데이터베이스 생성
- `SHOW DATABASES` : 데이터베이스 목록 확인
- `CREATE TABLE` : 테이블 생성
- `SHOW TABLES` : 테이블 목록 확인
- `DROP` : 데이터베이스나 테이블 삭제
- 기본 키 등 테이블의 필드 정의 방식 이해

## 5. 주요 SQL 명령어
- **INSERT** : 행 삽입
- **SELECT** : 조건에 맞는 데이터 조회
- **UPDATE** : 기존 데이터 수정
- **DELETE** : 기존 데이터 삭제
- `WHERE` : 조회·수정·삭제 대상 조건 지정

## 6. SQL 파일과 실행
- 여러 SQL 문장을 `.sql` 파일에 저장하고 실행 가능
- 테이블 생성과 샘플 데이터 입력 등의 작업을 반복할 때 활용

## 7. 핵심 정리
- DBMS·클라이언트·데이터베이스·테이블의 차이 구분
- CRUD 작업과 이에 대응하는 SQL 문법 이해
