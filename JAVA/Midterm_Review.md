# JAVA프로그래밍응용 중간고사 복습 정리

> 7주차에 업로드된 **중간고사 문제 유형 자료**와 4·5주차 실습 자료를 바탕으로 정리한 복습 항목입니다. 문제 유형 예시는 실제 출제를 확정하는 목록이 아닙니다.

## 1. 클래스와 객체
- 클래스·객체·인스턴스·생성자의 의미 구분
- 필드와 메서드, 인스턴스 멤버와 static 멤버
- 메서드 오버로딩과 생성자 호출

## 2. 상속과 다형성
- `extends`, `super()`, `super.메서드()`
- 부모·자식 생성자 실행 순서
- 메서드 오버라이딩과 접근 제한자
- 추상 클래스의 `abstract`, 인터페이스의 `implements`

## 3. 컬렉션
- `ArrayList<E>`, `Vector<E>`, `HashMap<K,V>`의 기본 사용
- 키·값 저장과 조회 (`put()`, `get()`)
- 컬렉션을 반복문으로 순회하고 객체와 연결하기

## 4. 입출력·CSV
- 문자 스트림과 바이트 스트림
- `FileReader`, `FileWriter`, `BufferedReader`
- CSV 한 줄 읽기·필드 구분·자료형 변환·컬렉션 저장

## 5. 실습 문제 복습 방향
- 빈칸 개념 문제와 코드 흐름 파악
- 4주차 미션의 컬렉션·HashMap 활용
- 5주차 미션의 파일 처리와 객체지향 구조 결합
- 예제 결과를 외우기보다 메서드가 수행하는 역할을 이해

## 6. 핵심 정리
- 업로드된 문제 유형 자료는 연습 기준이며 실제 시험 문항을 확정하는 근거로 사용하지 않음
- Java 기초 → 상속·추상화 → 제네릭·컬렉션 → 파일 처리 흐름으로 반복 학습
