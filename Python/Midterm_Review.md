# Python프로그래밍 중간고사 내용 정리

> **범위:** 공부하기 대화에서 확인한 **변수·자료형, 연산자, 조건문, 반복문, 리스트·튜플·딕셔너리**입니다.
> **자료 기준:** 고정된 Python 공부하기 대화의 학습 범위와 복습 내용을 정리했습니다. 원본 주차별 강의교안 전체는 확인되지 않았으므로 임의로 상세 주차를 지정하지 않았습니다.

## 1. 변수·자료형·입출력
- **변수** : `=`로 값 저장. `int`(정수), `float`(실수), `str`(문자열), `bool`(논리값).
- `input()`의 반환값은 **문자열**이므로 숫자 계산에는 `int(input())` 등으로 변환.
- `print()`로 결과 출력, `type()`으로 자료형 확인.

## 2. 연산자
- **산술** : `+`, `-`, `*`, `/`(실수 나눗셈), `//`(몫), `%`(나머지), `**`(거듭제곱).
- **비교** : `==`, `!=`, `>`, `<`, `>=`, `<=`.
- **논리** : `and`, `or`, `not`.
- **구분** : `=`은 대입, `==`는 값 비교.

## 3. 조건문
- `if` → `elif` → `else` 순서로 조건을 판별.
- 들여쓰기로 실행할 코드 블록을 구분.
- 비교·논리 연산자를 조합하여 여러 조건을 처리.

## 4. 반복문
- **for** : 정해진 범위나 시퀀스를 차례로 반복.
- **range(start, stop, step)** : `stop`은 **포함하지 않음**.
- **while** : 조건이 참인 동안 반복; 종료 조건 확인.
- **break** : 반복문 종료 / **continue** : 현재 반복의 나머지를 건너뛰고 다음 반복으로 이동.
- 중첩 반복문의 **실행 횟수·출력 결과**를 추적하는 연습.

## 5. 리스트·튜플·딕셔너리
| 자료구조 | 특징 | 핵심 사용법 |
|---|---|---|
| **list** | 순서가 있으며 수정 가능 | 인덱스는 0부터, `append()`·`insert()`·`remove()`·`pop()` |
| **tuple** | 순서가 있지만 원소 변경 불가 | `(1, 2, 3)`, 인덱스 접근 가능 |
| **dict** | 키와 값의 쌍으로 저장 | `data["key"]`로 접근, `keys()`·`values()` |

## 6. 코드 읽기 핵심
- `append(x)` : 리스트 끝에 추가 / `insert(i,x)` : 지정 위치에 삽입.
- `remove(x)` : 값에 해당하는 요소 삭제 / `pop(i)` : 인덱스의 요소 제거·반환.
- 리스트의 값 변경은 가능하지만 튜플 요소를 직접 수정할 수는 없음.
- `random.randrange()`는 끝값 미포함, `random.randint(a,b)`는 양 끝값 포함.
- 실행 결과를 읽을 때 변수 값, 인덱스, 반복 횟수를 차례대로 추적.

## 7. 핵심 정리
- 중간고사 복습은 **형변환 → 연산자 → 조건문 → 반복문 → 기본 자료구조** 순서로 확인.
- **2차원 리스트·배열과 turtle은 해당 Python 시험 범위에서 제외**한다고 명시하셨으므로 넣지 않았습니다.
