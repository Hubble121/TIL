# JAVA프로그래밍응용 1주차 배운 내용 정리

## 1. 과목의 학습 목표
- **고급 Java 프로그래밍**의 기초가 되는 객체지향 문법과 활용 방법을 학습
- 기존에 배운 Java 문법을 복습하고 이후 컬렉션, 입출력, 스레드 등의 내용을 학습
- 개념 이해와 프로그램 작성 실습을 함께 진행

## 2. 주요 학습 범위
- **Java 기초 복습** : 클래스, 메서드, 생성자, 접근 제한자
- **객체지향** : 상속, 오버라이딩, 추상 클래스, 인터페이스
- **제네릭과 컬렉션** : 여러 객체를 저장하고 다루는 자료구조
- **입출력 스트림** : 파일에서 데이터를 읽고 쓰는 방법
- **추후 학습** : 멀티스레딩, GUI, 네트워크, 데이터베이스 프로그래밍

## 3. 프로그래밍 학습 방향
- 객체가 맡는 역할과 메서드 호출 흐름을 이해
- 문법을 실제 코드에 적용하고 실행 결과를 확인
- 입력·출력과 오류 발생 원인을 함께 기록

## 4. 핵심 정리
- 클래스와 객체의 관계를 이해하는 것이 이후 학습의 기초
- 컬렉션과 파일 입출력은 객체지향 설계를 활용하는 핵심 내용
- 각 기능의 문법뿐 아니라 언제 사용하는지 구분하는 것이 중요
