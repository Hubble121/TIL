# 웹자바프로그래밍입문 8장 내용 정리

## 1. 쿠키(Cookie)
- **Cookie** : 브라우저에 저장되어 요청과 함께 서버에 전달될 수 있는 작은 데이터
- `new Cookie(name, value)` : 쿠키 객체 생성
- `response.addCookie(cookie)` : 응답에 쿠키 추가
- `request.getCookies()` : 요청에 포함된 쿠키들을 읽음
- `setMaxAge()` : 쿠키의 유지 시간 지정
- 같은 이름의 쿠키에 최대 나이 0을 설정하여 삭제 처리

## 2. 세션(Session)
- **Session** : 서버에서 사용자별 상태를 관리하는 방식
- 사용자에게 연결된 세션을 통해 로그인 상태 등 정보 저장
- `session.setAttribute(name, value)` : 속성 저장
- `session.getAttribute(name)` : 속성 조회
- `session.removeAttribute(name)` : 속성 제거

## 3. 쿠키와 세션 비교
- 쿠키는 브라우저 측에 데이터가 저장될 수 있음
- 세션은 서버에서 상태를 관리하고 클라이언트에는 세션 식별자가 전달될 수 있음
- 로그인 정보는 강의자료에서 쿠키 예제로 시작한 뒤 세션 속성 기반 구현으로 발전

## 4. 로그인과 로그아웃
- 로그인 폼에서 ID와 비밀번호 전달
- 서버에서 입력 정보를 확인하고 로그인 성공 시 세션 속성 설정
- 로그아웃 시 사용자 관련 세션 속성 제거
- 로그인 여부에 따라 화면 표시를 다르게 구성

## 5. 데이터베이스를 이용한 로그인
- 회원 정보를 담는 테이블 준비
- 입력받은 계정 정보와 DB의 회원 정보를 비교
- 로그인 성공 시 사용자 ID와 이름 등을 세션 속성으로 저장
- 실패 시 사용자에게 오류를 안내

## 6. 회원가입과 회원 정보 수정
- **회원가입** : 폼 입력 → 중복 여부 등 확인 → DB에 회원 레코드 추가
- **정보 수정** : 기존 정보 조회 → 수정 폼 표시 → DB 데이터 업데이트
- 사용자 이름 등이 변경되면 화면에 사용하는 세션 속성도 함께 갱신

## 7. 핵심 정리
- 쿠키와 세션의 저장 위치 및 사용 목적 구분
- 로그인·로그아웃·회원가입의 요청과 세션 흐름 이해
