# JAVA프로그래밍응용 5주차 배운 내용 정리

## 1. 입출력 스트림
- **Stream** : 데이터를 일정한 방향으로 읽거나 쓰는 흐름
- **입력 스트림** : 외부 데이터를 프로그램으로 읽어 들임
- **출력 스트림** : 프로그램에서 외부로 데이터를 기록
- 스트림을 열고 데이터를 처리한 뒤 닫는 과정이 중요

## 2. 문자 스트림과 바이트 스트림
- **문자 스트림** : 텍스트 데이터를 문자 단위로 입출력
- **바이트 스트림** : 문자나 바이너리 데이터를 바이트 단위로 입출력
- 텍스트 파일과 이미지 등 바이너리 파일의 처리 방법을 구분

## 3. FileReader와 FileWriter
- **FileReader** : 파일의 문자 데이터를 읽는 입력 스트림
- **FileWriter** : 파일에 문자 데이터를 쓰는 출력 스트림
- `read()` : 데이터를 읽음. 파일 끝은 `-1`로 판단하는 경우가 있음
- `write()` : 문자 또는 문자열 데이터 기록
- `close()` : 사용한 스트림을 닫음

## 4. 버퍼를 이용한 파일 처리
- **BufferedReader** : 문자 입력을 버퍼로 처리하는 클래스
- `readLine()` : 파일에서 한 줄씩 읽기
- **BufferedWriter** : 출력 데이터를 버퍼로 기록
- 필요한 작업이 끝나면 버퍼와 파일 자원을 정리

## 5. 파일과 예외 처리
- **File** : 파일 또는 경로에 관한 정보를 다루는 클래스
- 파일이 없거나 접근할 수 없는 경우 입출력 예외 발생 가능
- `IOException`, `try-catch` 또는 `throws`를 이용한 예외 처리
- 스트림이 닫히지 않는 문제를 피하도록 자원 해제 과정 확인

## 6. CSV 파일 처리
- **CSV(Comma Separated Values)** : 쉼표로 필드, 줄바꿈으로 레코드를 구분한 텍스트 형식
- 파일을 한 줄씩 읽은 뒤 `split(",")` 등으로 데이터를 분리하는 기초 방법
- 분리한 문자열을 `Integer.parseInt()` 등으로 변환하여 객체나 컬렉션에 저장
- 저장된 컬렉션을 순회하거나 가공한 결과를 출력

## 7. 컬렉션과 파일 입출력 연결
- 파일에서 여러 레코드를 읽기 → 필요한 필드 분리 → 객체 생성 → 컬렉션에 추가
- 데이터를 객체 단위로 관리하면 조회와 출력 기능을 분리하기 편리함
- 파일 입력·자료구조·메서드의 책임을 구분하며 구현

## 8. 핵심 정리
- 문자 스트림과 바이트 스트림의 차이를 이해
- `FileReader`, `FileWriter`, `BufferedReader`의 사용 목적 구분
- CSV 데이터를 읽어 컬렉션에 저장하는 전체 흐름 복습
