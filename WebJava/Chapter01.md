# 웹자바프로그래밍입문 1장 내용 정리

## 1. HTML과 JSP
- **HTML** : 웹 브라우저가 화면에 표시할 문서의 구조를 작성하는 언어
- **JSP(JavaServer Pages)** : HTML 문서 안에 Java 기반의 서버 처리 코드를 작성하는 웹 기술
- HTML 파일과 달리 JSP는 서버에서 처리한 결과가 웹 브라우저에 전달됨

## 2. JSP 프로그램의 동작 과정
1. 브라우저가 JSP 페이지를 요청
2. 웹 서버 및 서블릿 컨테이너에서 JSP를 처리
3. 서버에서 생성한 HTML 응답을 브라우저에 전송
4. 브라우저가 응답 결과를 표시

## 3. JSP 실행 환경
- **JDK** : Java 프로그램의 개발 및 실행에 필요한 도구
- **OpenJDK** : Java 플랫폼의 공개 구현
- **Apache Tomcat** : JSP와 서블릿을 실행하는 컨테이너
- **webapps/ROOT** : 톰캣의 기본 웹 애플리케이션에 속하는 파일을 둘 수 있는 경로
- **JAVA_HOME / PATH** : JDK 실행 위치를 지정하는 환경 설정

## 4. localhost와 포트
- **localhost(127.0.0.1)** : 현재 컴퓨터를 가리키는 호스트명
- **포트(Port)** : 서버에서 실행 중인 서비스를 식별하는 번호
- 강의 실습에서는 톰캣 기본 포트와 실습실 프로그램 충돌을 피하기 위해 포트를 변경하여 사용
- 서버가 실행 중이고 요청 URL과 파일 위치가 일치해야 JSP가 정상 실행됨

## 5. 핵심 정리
- JSP는 웹 브라우저가 직접 실행하는 파일이 아니라 서버에서 처리되는 프로그램
- JDK, 톰캣, JSP 파일의 저장 경로와 접속 포트의 관계 이해
