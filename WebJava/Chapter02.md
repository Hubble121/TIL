# 웹자바프로그래밍입문 2장 내용 정리

## 1. JSP 프로그램의 기본 형태
- JSP 파일의 확장자는 `.jsp`
- HTML 문서에 JSP 코드를 포함하여 동적인 웹 페이지를 생성
- **스크립틀릿(Scriptlet)** : `<% ... %>` 안에 Java 문장을 작성
- **page 지시자(Directive)** : `<%@ page ... %>`를 사용하여 JSP 페이지 설정을 지정

## 2. page 지시자
- `language="java"` : 사용 언어 지정
- `contentType="text/html; charset=UTF-8"` : 응답 문서의 종류와 인코딩 설정
- `pageEncoding="UTF-8"` : JSP 파일의 인코딩 설정
- `import` : 필요한 Java 클래스를 가져옴

## 3. JSP 화면 출력
- `out.print()` / `out.println()` : 브라우저로 전달될 응답에 출력
- `System.out.println()`은 서버 콘솔 출력으로 브라우저에 직접 표시하는 것과 다름
- HTML에서 여러 개의 연속된 공백과 줄바꿈은 일반적으로 한 공백처럼 표시될 수 있음

## 4. JSP 파일 저장과 실행
- JSP는 톰캣이 관리하는 웹 애플리케이션 폴더 안에 저장
- 브라우저에서 해당 서버와 경로를 가진 URL로 요청
- HTML 파일을 로컬에서 여는 것과 달리 서블릿 컨테이너의 처리가 필요

## 5. 주석(Comment)
- **Java 주석** : `//`, `/* ... */`를 Java 코드 영역에서 사용
- **HTML 주석** : `<!-- ... -->`는 브라우저의 소스 보기에서 확인 가능
- **JSP 주석** : `<%-- ... --%>`는 서버 처리 중 제거되어 응답 소스에 포함되지 않음

## 6. 핵심 정리
- 스크립틀릿과 page 지시자, HTML 영역의 역할 구분
- JSP 출력 메서드와 주석의 차이 이해
