# JAVA프로그래밍응용 중간고사 내용 정리

> **범위:** 2~6주차 학습 내용 및 7주차 중간고사 예시 문제(Q1~Q6). 공부하기 대화·기존 TIL·강의자료의 핵심을 정리했습니다.
> **주의:** 예시 문제의 유형은 실제 출제 확정 목록이 아닙니다.

## 1. 핵심 개념

| 영역 | 기억할 내용 |
|---|---|
| **클래스와 객체** | 클래스(설계도), 인스턴스(생성 객체), 생성자(초기화), 인스턴스 멤버와 `static` 멤버 구분 |
| **상속** | `extends`, **부모 생성자 먼저 실행**, `super()`로 부모 생성자 호출. 부모에게 기본 생성자가 없으면 올바른 호출 지정 |
| **메서드** | **오버로딩** = 같은 이름·다른 매개변수 / **오버라이딩** = 자식에서 부모 메서드 재정의 |
| **추상 클래스·인터페이스** | `abstract`는 공통 구조와 미완성 메서드 정의, `implements`는 인터페이스의 계약 구현 |
| **제네릭·컬렉션** | `ArrayList<E>`·`Vector<E>`는 리스트, `HashMap<K,V>`는 키·값 쌍. `put()` 저장·`get()` 검색 |
| **파일 처리** | `FileReader`(문자 입력), `BufferedReader.readLine()`(줄 읽기), `split(",")`(기초 CSV 분리), 자원 닫기 |
| **Swing GUI** | `JFrame` 창, **FlowLayout**(순서대로 흐름 배치), **GridLayout**(행·열 격자 배치) |

## 2. 중요 실습 흐름

### 상속·생성자
- `Shape`와 `Rectangle`, `Person`과 `Student` 예시에서 **부모 생성자 호출과 출력 순서** 확인.
- `super("문자열")`처럼 부모에게 존재하는 생성자와 인수를 맞춰야 함.
- 메서드 재정의 때 `@Override` 및 `super.메서드()`의 역할 구분.

### Drink / DrinkStore
- **Drink** : 이름·가격 등 필드, 생성자, getter·setter·`toString()`.
- **DrinkStore** : `HashMap<String, Drink>`에 저장하고 `addDrink()`, `searchDrink()`, `printAllDrinks()`로 관리.
- **DrinkTest** : 입력을 받아 저장소의 기능을 호출하는 실행 부분.
- **CSV 연계** : 헤더 처리 → 한 줄 읽기 → `split(",")` → 이름·가격·별점 변환 → Drink 객체 생성 → 저장·조회.

### Swing
- `JFrame`에 배치 관리자 설정 후 컴포넌트 추가.
- **FlowLayout**과 **GridLayout**을 구별하고, 배치 결과와 컴포넌트 추가 순서 복습.

## 3. 중간고사 예시 문제 복습
- **Q1 계열** : 인스턴스·생성자·오버로딩/오버라이딩·`abstract`·`implements` 등 용어.
- **Q3~Q4 계열** : 상속 및 생성자 오류 찾기·수정, `Person`–`Student` 코드 완성.
- **Q5~Q6 계열** : Swing `JFrame` 및 레이아웃 코드 이해·완성.
- **4~5주차 실습** : Drink 객체지향 설계와 HashMap, CSV 파일 처리.
- 공부할 때 특히 강조된 내용은 **상속·생성자 오류(Q3)**와 **FlowLayout(Q5)**.

## 4. 핵심 정리
- **상속 시 생성자 호출**, **오버로딩과 오버라이딩**, **인터페이스 구현**을 구분.
- 파일·컬렉션 실습은 **입력 → 객체 변환 → 저장소 등록 → 검색·출력** 흐름으로 이해.
