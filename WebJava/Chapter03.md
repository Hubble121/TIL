# 웹자바프로그래밍입문 3장 내용 정리

## 1. Eclipse와 IDE
- **IDE(통합 개발 환경)** : 편집·실행·디버깅을 위한 개발 도구
- **Eclipse** : Java 및 웹 애플리케이션 개발에 사용하는 IDE
- JSP 개발에는 Enterprise Java and Web Developers용 구성과 서버 설정이 필요

## 2. Workspace와 Perspective
- **Workspace** : Eclipse 프로젝트와 설정을 관리하는 작업 공간
- **Perspective** : 작업 목적에 따라 편집기와 도구 창 배치를 제공하는 구성
- JSP 프로젝트에서 서버·웹 개발 관련 화면과 기능을 확인

## 3. Tomcat 서버 등록
- Eclipse의 **Servers** 항목에서 Tomcat을 등록
- JDK와 서버 경로를 지정하고 서버 실행 여부 확인
- 포트 충돌 시 Eclipse가 사용하는 서버 설정과 실제 사용 포트 확인

## 4. 프로젝트와 인코딩 설정
- **Dynamic Web Project** : 웹 애플리케이션 개발 프로젝트
- JSP 파일 생성 후 필요한 코드를 작성
- 한글 출력을 위해 프로젝트 및 HTML·JSP의 UTF-8 인코딩 확인

## 5. 프로젝트 실행과 배포
- Eclipse에서 지정된 서버로 웹 애플리케이션 실행
- **WAR(Web Application Archive)** : 웹 애플리케이션을 배포하기 위한 압축 파일 형식
- 프로젝트 실행 환경과 배포 환경의 차이를 이해

## 6. 핵심 정리
- Workspace, Perspective, 웹 프로젝트, Tomcat 연결의 역할 구분
- 웹 애플리케이션은 서버에서 실행하며 WAR로 배포 가능
